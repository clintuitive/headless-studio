# The Headless Studio — intermediate edition

The maintained manuscript behind the website and the EPUB. It describes a
studio built from score data, performed sources, processed stems and delivery
files, and it is written for an intermediate programmer with introductory
Python and no audio background.

Start with the self-contained sketches and the sampler demo — they need only
NumPy and SciPy. The plugin and SoundFont chapters describe optional instrument
paths; the album chapters cover the documented synthesis and licensed sample
sources.

Code fragments illustrate the concept under discussion unless they are
explicitly presented as complete commands or programs. The scripts in the
repository are the runnable source of truth.
